# 前端快速入门

## 立即开始

访问 http://localhost:3000 使用管理控制台。

## 页面导航

- **主页**: http://localhost:3000 - 概览、统计、近期活动
- **Agent 管理**: http://localhost:3000/agents - 正式 Agent 管理页面
- **兼容入口**: `/agents-modern` 会重定向到 `/agents`，`/demo-new-design` 会重定向到首页；这两个地址不再是独立前端。

## 语言切换

点击右上角的语言选择器，可切换中文、English 和日本語。

## 开发

```powershell
npm run dev
```

完整的本地初始化、账号和模型配置见 `../docs/runbooks/local-demo.md`。
