# 基线负载测试报告

## 测试环境

- 本地 API 服务 `http://127.0.0.1:8000`，健康端点
- Python 标准库线程池，独立请求，无生产数据写入

## 测试结果

| 场景 | 请求 | 成功率 | P50 | P95 | P99 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 100 并发健康检查 | 100 | 100% | 457.24 ms | 540.58 ms | 542.83 ms |
| 50 并发健康检查（混合基线） | 50 | 100% | 70.17 ms | 110.13 ms | 111.05 ms |

命令：`python scripts/load_test.py`。两组均返回 HTTP 200，无错误类型。

## 结论

基线负载测试通过，可作为 MVP 验收证据。正式生产发布仍需 k6/Gatling 容量压测、故障注入和渗透测试。
