# 权限与安全设计

_负责人：安全与平台团队｜状态：基线设计｜版本：v1.1｜最后更新：2026-08-24_

---

## 权限模型

权限格式为 `resource:action:scope`，资源包括 agent、skill、tool、knowledge_base、conversation、workflow、audit 和 admin；操作包括 create、read、update、delete、execute、publish、approve 和 export；范围包括 own、team、tenant、all。

认证后服务端按 `userId + tenantId + roles` 计算有效权限。`own` 必须验证 createdBy；team 必须验证团队成员关系；任何管理员权限仍不能绕过平台禁止的高风险 Tool。

## 安全边界

- 浏览器只持有短期会话，不保存供应商密钥。
- API、Gateway、Worker、Sandbox 之间使用服务身份和最小权限。
- Secret Manager 管理模型、渠道、数据库和插件凭据，支持轮换和撤销。
- Tool 执行隔离文件根目录、网络域名、CPU、内存、时长和进程权限。
- 所有外部输入是数据，不是指令；system policy 与用户/网页/附件内容物理分区。

## 威胁与控制

Prompt Injection：外部内容标记为不可信；工具调用始终重新授权。跨租户泄漏：仓储层强制 tenant scope，RLS 可作为纵深防御。SSRF：阻止 loopback、私网、云元数据和 file 协议，解析后再次检查 IP。恶意 Skill/Plugin：审核、签名/哈希、依赖扫描、独立进程和能力声明。成本攻击：滑动窗口限流、预算、递归深度和熔断。日志泄露：字段级脱敏和哈希，指标禁止原始输入。文件攻击：MIME/大小检查、病毒扫描、路径规范化和输出目录隔离。

## 高风险动作

外部发送、删除、支付、权限变更、命令执行和敏感数据导出默认 deny 或 ask。审批请求显示最小必要上下文、工具、参数摘要、风险和过期时间；批准必须绑定版本和一次性 request token。

## 安全运营

审计事件不可由普通管理员删除；导出、权限变更、密钥访问和紧急停用必须记录。异常登录、跨租户拒绝、工具拒绝、成本突增和插件异常触发告警。建立漏洞响应、凭据泄露、数据泄漏和服务降级 Runbook。

## 身份与数据治理

- 会话使用短期访问凭据和可撤销刷新凭据；刷新时轮换并检测重放，注销和停用用户立即撤销会话
- 租户上下文只能来自已验证凭据、服务间身份或受信任的网关上下文，不能信任 URL、请求体或 WebSocket payload
- 数据按公开、内部、敏感、受限分级；受限数据禁止进入模型上下文、普通日志、指标和导出文件
- 审计事件至少包含 `eventId`、`tenantId`、主体、动作、资源、结果、原因、requestId、时间和脱敏摘要，并采用追加写入和访问留痕

## 安全基线与例外

默认拒绝网络、文件和进程能力；每个例外必须有能力清单、审批人、有效期、范围和回滚方式。供应商、插件和镜像进入生产前必须完成依赖漏洞扫描、许可证检查、签名校验和 SBOM 留存。安全例外不得由前端开关绕过，必须由服务端策略评估。

## 验收标准

- OWASP API、SSRF、越权、文件上传和密钥扫描通过。
- 7 类威胁均有自动化回归用例。
- 跨租户和越权请求既被拒绝又被审计。
- 密钥不出现在前端、日志、Prompt、备份导出和指标中。
