# ADR-0001：PostgreSQL 作为事务事实源

_负责人：架构委员会｜状态：已接受｜版本：v1.0｜最后更新：2026-08-24_

---

- 状态：已接受
- 日期：2026-08-24

## 背景

平台需要保证租户数据、发布版本、Run 状态、审批和审计记录的一致性，同时使用 Redis、对象存储和向量库承载缓存或大对象。

## 决策

PostgreSQL 作为业务事实和事务边界；Redis 只保存缓存、锁、队列元数据和短期幂等/审批加速数据；对象存储保存大文件；向量库保存可重建索引。跨存储写入采用 outbox/重试，不能把 Redis 作为唯一事实源。

## 影响与复审条件

该决策简化审计、版本和恢复的一致性，但要求数据库连接池、迁移和备份能力先达标。若单库容量、写入吞吐或地域容灾成为瓶颈，复审分片/多主方案，并保留租户级迁移路径。
